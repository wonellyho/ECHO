# 기능 5: 내 경험 탭을 겹쳐 쌓인 카드 스택으로 본다

(클로드 디자인 `ECHO Wireframes.dc.html` turn 2 / `2a`, 기존 `1d` 그리드 대체안)

## 완료 조건
(최대 5개까지. 눈으로 확인 가능한 것만)

- [ ] `/entries`에 기록들이 겹쳐진 카드 스택(제목 줄만 보이는 접힌 카드 + 최신 카드 1장은 기본 펼쳐진 상태)으로 보인다
- [ ] 접힌 카드를 탭하면 그 카드가 펼쳐지고, 이전에 펼쳐져 있던 카드는 접힌다 (한 번에 1장만 펼쳐짐)
- [ ] 펼쳐진 카드에는 본문 요약(`situation ?? raw_text`), 태그, 날짜, "상세 보기" 버튼이 보이고 누르면 `/entries/:id`로 이동한다
- [ ] 검색어/태그 필터/정렬(최신순·월별·프로젝트별·컬렉션별)을 바꾸면 스택 내용도 그대로 반영된다
- [ ] 조회 실패 시 (이미 구현된) "기록을 불러오지 못했습니다" + 다시 불러오기 버튼이 스택 영역 자리에 그대로 뜬다

## 안 되는 경우
(여기 안 적으면 처리도 안 됩니다)

- 기록이 0건이거나 필터 결과가 0건 → 스택 자리에 "쌓인 카드가 없습니다. 첫 경험을 기록하면 이 자리에 카드가 쌓입니다." + "기록 화면으로 가기" 버튼
- 로딩 중 → 접힌 카드 자리마다 회색 스켈레톤 바 표시 (개수는 고정 6장 정도로 흉내)
- 선택 모드(다중 선택 → 컬렉션 일괄 추가)에서는 스택 대신 기존 그리드+체크 UI를 그대로 쓴다 (스택과 선택 모드를 동시에 만들지 않음 — 아래 "이번에 안 하는 것" 참고)

## 이번에 안 하는 것
(안 적으면 시키지 않은 것까지 만들어 옵니다)

- 스와이프/드래그 제스처 — 탭으로만 펼침/접힘 전환
- 그룹(월별/프로젝트별/컬렉션별)마다 별도 스택으로 쌓기 — 이번엔 필터링된 결과를 하나의 스택으로만 표시. 정렬 모드가 "월별" 등이어도 스택 순서만 그 기준으로 정렬하고, 그룹 헤더/여러 스택 분리는 다음 슬라이스
- 선택 모드 UI를 스택형으로 새로 설계 — 선택 모드 진입 시엔 기존 그리드 뷰로 되돌아가는 방식 유지 (완료 조건에 없음)
- 카드 펼침/접힘 애니메이션의 물리 효과(스프링 등) 고급 튜닝 — CSS transition 정도로 충분

## 건드릴 파일
(새로 만들 파일 / 고칠 파일)

- **신규**: `src/components/EntryCardStack.tsx` — 스택 렌더링·펼침 상태 관리 컴포넌트 (filtered entries 배열을 받아 렌더링)
- **수정**: `src/pages/EntriesPage.tsx` — `selectMode`가 아닐 때는 `renderCard` 그리드 대신 `EntryCardStack` 사용, 로딩/빈 상태/에러 상태 분기는 기존 것 재사용
- **수정 없음(재사용)**: `src/lib/entryFilter.ts`, `src/lib/entryGrouping.ts`, `src/lib/tagColors.ts` — 필터/정렬/태그 색 로직 그대로

## 확인 방법
(테스트 + 직접 눌러볼 순서)

1. `npm run build` — 타입체크 통과 확인
2. `/entries`에서 기록 5개 이상 있는 계정으로 스택이 겹쳐 보이는지 확인
3. 접힌 카드 하나를 탭 → 그 카드가 펼쳐지고 이전 펼침 카드는 접히는지 확인
4. 펼쳐진 카드의 "상세 보기" → `/entries/:id`로 이동하는지 확인
5. 검색어/태그 필터 적용 → 스택 카드 수가 줄어드는지 확인
6. 정렬 모드를 "월별"로 바꿔 스택 순서가 바뀌는지 확인
7. "선택" 버튼을 눌러 선택 모드 진입 → 기존 그리드+체크 UI로 정상 전환되는지 확인
8. 네트워크 끊고 새로고침 → "기록을 불러오지 못했습니다" + 다시 불러오기 버튼 확인
