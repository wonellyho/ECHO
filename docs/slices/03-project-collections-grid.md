# 기능 3: 경험 목록을 프로젝트/월/컬렉션 기준으로 그리드로 모아보고, 기록에 프로젝트·컬렉션을 붙인다

## 완료 조건
(최대 5개까지. 눈으로 확인 가능한 것만)

- [ ] 기록탭에서 프로젝트 제목(선택, 자동완성)과 컬렉션(선택, 기존 선택 또는 새로 생성)을 함께 입력해 저장할 수 있다
- [ ] 내 경험 탭에서 "프로젝트별/월별/컬렉션별" 중 하나를 고르면 그 기준으로 섹션 헤더 + 카드 그리드(모바일 2열 → 데스크톱 4열)로 보인다
- [ ] 카드는 전부 같은 크기이고 프로젝트 제목/상황 요약/날짜만 보이며, 텍스트가 길면 말줄임(...)으로 잘린다
- [ ] "선택" 모드로 카드 여러 개를 고른 뒤 기존 컬렉션에 추가하거나 새 컬렉션을 만들어 한번에 옮길 수 있다
- [ ] 네비게이션 바가 화면 상단에 고정되어 항상 보인다

## 안 되는 경우
(여기 안 적으면 처리도 안 됩니다)

- 프로젝트 제목/컬렉션을 안 정했을 때 → 저장은 되고, 목록에서 해당 기준으로 묶을 때 "미분류" 섹션에 모인다
- 프로젝트별/컬렉션별 그룹 기준인데 그 그룹이 하나도 없을 때(전부 미분류) → "미분류" 섹션 하나만 보인다
- 태그+키워드 검색과 그룹 기준은 동시에 적용된다 (검색 결과를 그룹 기준으로 묶어서 보여줌) **[계산/판단 → 테스트 대상]**
- 컬렉션 이름 없이 "새 컬렉션 만들기"를 시도하면 생성되지 않는다
- 로그인 안 한 상태로 접근 → 기존 라우팅 규칙대로 로그인 화면으로
- 섹션 정렬 순서: "미분류"는 그룹 기준과 무관하게 항상 맨 마지막. 그 외 섹션은 프로젝트별/컬렉션별은 그 그룹에서 가장 최근 기록이 있는 순(내림차순), 월별은 최신 월부터 **[계산/판단 → 테스트 대상]**

## 이번에 안 하는 것
(안 적으면 시키지 않은 것까지 만들어 옵니다)

- 컬렉션 이름 수정/삭제 UI — 생성과 기록 추가만
- 하나의 기록이 여러 컬렉션에 속하는 것 — 기록당 컬렉션 최대 1개
- 프로젝트 자체를 별도 엔티티로 관리(이름 변경 시 과거 기록 일괄 변경 등) — `project_title`은 기록마다 저장되는 자유 텍스트일 뿐, 프로젝트 테이블은 만들지 않음
- 그룹 기준 다중 선택(예: 프로젝트+월 동시 그룹핑)
- 카드 정렬 순서 커스터마이징(드래그 등) — 그룹 내부는 최신순 고정

## 건드릴 파일
(새로 만들 파일 / 고칠 파일)

- **신규(DB)**: `supabase/schema.sql` — `collections` 테이블 + RLS, `entries.project_title`/`entries.collection_id` 컬럼 (+ Supabase SQL Editor에 직접 실행)
- **수정**: `src/types/index.ts` — `Entry`에 `project_title: string | null`, `collection_id: string | null` 추가, `Collection` 타입 신규
- **신규**: `src/lib/entryGrouping.ts` (그룹 기준별로 섹션 나누는 순수 함수) + `.test.ts`
- **수정**: `src/pages/RecordPage.tsx` — 프로젝트 제목 입력(datalist 자동완성) + 컬렉션 선택/생성 UI, insert 시 두 필드 포함
- **수정**: `src/pages/EntriesPage.tsx` — 그룹 기준 선택 UI, 반응형 그리드, 카드 컴포넌트(말줄임 처리), 선택 모드 + 컬렉션 일괄 추가
- **수정**: `src/App.tsx` — `<nav>`를 `<main>` 위로 이동, `sticky top-0`로 변경(기존 하단 고정용 `pb-16` 제거)

## 확인 방법
(테스트 + 직접 눌러볼 순서)

1. `npm run test` — `entryGrouping` 새 테스트 통과 확인 (기존 테스트도 계속 통과)
2. `npm run build` — 타입체크/빌드 통과 확인 (schema 변경에 맞춰 타입 정합성 포함)
3. `npm run dev:vercel`에서: 기록탭에서 프로젝트 제목 입력(자동완성 뜨는지) + 새 컬렉션 만들며 저장
4. 내 경험 탭: 프로젝트별/월별/컬렉션별 전환하며 섹션 헤더와 카드 그리드 확인, 화면 폭 줄여서 2열로 바뀌는지 확인
5. 검색어/태그 필터를 걸고 그룹 기준을 바꿔봐서 필터+그룹이 함께 적용되는지 확인
6. 카드 여러 개 선택 모드로 고른 뒤 컬렉션에 일괄 추가, 새로고침해도 유지되는지 확인
7. 네비게이션이 스크롤해도 상단에 고정돼 있는지 확인
